One-sentence: every functional icon in the system — never hand-roll an SVG or reach for an emoji.

```jsx
<Icon name="ruler" size={18} />
```

Sizes in use: 14 (inline with small text), 18 (buttons, list rows), 24 (feature rows), 32 (empty states). Inherits `color` from its parent, so set the colour on the text element around it.
